# FFEOE · páginas públicas

Copia generada de los formularios públicos de FFEOE (empresa, valoración,
alumnado, elección de empresa) para servirlos fuera de Google. No contiene
datos: cada página habla con el servidor de Apps Script con su enlace personal.

No se edita a mano: se genera con `herramientas/estaticas.js` del proyecto
`ffeoe-app` al publicar.
